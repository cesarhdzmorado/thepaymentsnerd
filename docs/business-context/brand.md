### **🎨 Colors**

**Primary Palette:**

- **Blue**: #2563eb - Your main brand color for interactive elements
- **Indigo**: #4f46e5 - Secondary accent for gradients and emphasis
- **Cyan**: #06b6d4 - Dark mode alternative accent

**Light Mode:**

- Background: #fafaf9 (warm off-white)
- Foreground: #0a0a0a (nearly black)
- Cards: Semi-transparent white with backdrop blur (glassmorphism)

**Dark Mode:**

- Background: #0a0e1a (deep navy, OLED-friendly)
- Foreground: #f5f5f4 (warm light)
- Cards: Semi-transparent slate surfaces

**Status Colors:**

- Success: #22c55e (green)
- Warning: #f59e0b (amber)
- Error: #ef4444 (red)

### **✍️ Typography**

**Fonts:**

- **Archivo** (Display) - Used for logo, headings - Modern, geometric, tech-forward
- **Inter** (Body) - Used for all content - Clean, readable

**Usage:**

- Main headings: font-display text-4xl+ font-black tracking-tighter
- Body: font-sans with standard weights

### **🎭 Design Style**

**Aesthetic:** Modern, minimalist tech with glassmorphism

**Key Features:**

- Semi-transparent cards with backdrop blur (14-16px)
- Subtle gradient glows for depth
- Grid pattern backgrounds
- Smooth animations (fade-in-up, scale, slide effects)
- Full light/dark mode support

**Shadows:**

- Light: Soft, subtle depth
- Dark: Deeper, more pronounced
